## 这是个什么游戏

你辞掉了工作（或者从来就没上过班），注册了一家只有你一个人的公司。没有通关，没有倒计时——你想做多久做多久，直到你主动收手，或现实替你按下终止键。

游戏的底层状态机不是抽象数值，而是一套「人生操作系统」：

- **状态切片**：本体五元（健康＝睡眠40%+情绪25%+饮食20%+运动15% / 信息 / 认知 / 技能 / 品性）× 衍生四元（资产 / 关系 / 权力 / 影响力）。本体崩了，衍生打折——你没法在连续失眠时谈下大单。
- **System1 / System2 双决策**：精力见底或压力爆表时，游戏进入「情绪模式」——理性选项被隐藏、冲动选项浮现、执行劣化。休息不是回血按钮，是保住决策权的战略资源。
- **过劳 · 猝死 · 恢复三线**：隐性疲劳暗中累积，双强预警后概率公开；过劳 3 次硬撑倒下，无视预警则可能迎来真正的终局。中断不删档，最低日保你回场。
- **项目组合**：14 种项目类型走完整生命周期（想法→验证→开发→发布→增长→成熟→衰退/转型），真实潜力按幂律抽取且对你不可见——用户访谈只能让读数收敛，不能消除不确定。
- **AI 智能体与 Token 经济**：雇 7 类智能体（客服/获客/内容/销售/法务财务/注册代办/全能管家），烧 Token 赚差价；单位经济面板实时显示毛利率；自动化程度 ≥85 触发「幽灵公司」——也通往一人独角兽的隐藏结局。
- **灰产线**：Token 中转站与账号代充，短多长空，账单总会寄到。
- **平台政策**：8 家平台各有流量系数与危险度，AI 内容标识义务、新号观察期、封号清算，一样不少。
- **开放式结局**：17 种结局 + 五维人生报告（财务/事业/关系/身心/意义）。平凡收场也是体面收场。

游戏内 32 条知识点全部标注现实来源（行业调研 / 设计手记 / 一手实践），经营者会学到真东西。

## 本地运行

```bash
npm install
npm run dev        # 本地开发
npm run build      # 产出 dist/（纯静态，可托管于任意子路径）
npm test           # 196 项测试
npm run sim        # 平衡模拟器（8 策略机器人 × 150+ 局，约 30 秒）
```

技术栈：Vite + TypeScript（strict）+ 零运行时依赖 + 全代码像素（无任何图片/AI 生成素材）+ seeded RNG（同种子同命运流）。

> 代码注释中的「技术文档 §N / 设计方案 §N」为开发期内部设计文档的章节引用，文档本身不随本仓库发布。

## 部署

`dist/` 为纯静态产物（`base:'./'` 相对路径），可部署在任意子路径。本仓库通过 GitHub Actions 自动构建并发布到 GitHub Pages。
